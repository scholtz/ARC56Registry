# Arc56.Generated.akita-protocol.akita-sc

Auto-generated typed Algorand smart-contract clients for **[akita-protocol/akita-sc](https://github.com/akita-protocol/akita-sc)**,
built from the [ARC-56](https://github.com/algorandfoundation/ARCs/blob/main/ARCs/arc-0056.md)
specs listed below.

Generated by the [Arc56Registry](https://github.com/scholtz/Arc56Registry) pipeline,
using the [scholtz/dotnet-algorand-sdk](https://github.com/scholtz/dotnet-algorand-sdk) ARC-56 client generator.
Do not edit these files by hand — they are regenerated automatically whenever the
source ARC-56 spec changes.

## Install

```bash
dotnet add package Arc56.Generated.akita-protocol.akita-sc
```

This package depends on [`Algorand5`](https://www.nuget.org/packages/Algorand5/) for
ABI encoding, transaction building, and algod/indexer access.

## Basic usage

Each contract in this package lives in its own namespace (a hash of its source URL is
appended to keep multiple contracts in the same repository from colliding), and
exposes a `<Name>Proxy` class:

```csharp
using Algorand.Algod;
using Arc56.Generated.akita_protocol.akita_sc.AkitaSocialPlugin_v0_0_3_1227991d;

using var httpClient = HttpClientConfigurator.ConfigureHttpClient(AlgodConfiguration.MainNet);
var algod = new AlgodClient(httpClient);
var client = new AkitaSocialPluginProxy(algod, appId: 123456789);

// call a contract method, e.g.:
// var result = await client.SomeMethod(...);
```
